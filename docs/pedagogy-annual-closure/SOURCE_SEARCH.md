# Journal de recherche officielle — 20 septembre 2026

Point d’entrée : [programmes officiels MINESEC](https://www.minesec.gov.cm/web/index.php/fr/systeme-educatif/progammes-officiels), index enseignement général et hôte documentaire `files.minesec.gov.cm`. Recherche ciblée, non exhaustive de tout le Web. Aucun résultat tiers ne sert de preuve de programme.

Requêtes effectuées avec restriction aux domaines officiels, seules ou regroupées :

- Français / Anglais / EPS / travail manuel, programmes 6e–5e ; recherches séparées « Français » « 6e », « Anglais » « 6e », « Éducation physique » programme 6e–3e, « Travail manuel » programme guide.
- PCT / SVT / informatique / EPS 4e–3e ; puis « PCT » « 4e », « SVT » « 3e », « informatique » « 4ème » « 3ème » et « informatique » « 6ème » « 5ème » programme corrigé.
- Chemistry / English Language / French / Geography / History / Citizenship syllabus Form 1–2 ; recherches séparées Chemistry Form 1, English Language Form 1, French Form 2, Geography Form 1, History Form 1, Citizenship Form 2.
- English Language / Literature in English syllabus Forms 3–5 ; Chemistry syllabus Forms 1–5 corrigendum.
- Computer Science / ICT Lower Sixth / Upper Sixth syllabus final.
- Anglais / chimie / physique Seconde programme définitif ; recherche d’un texte d’adoption et de remplacement des pièces collectées.
- MINEDUB curriculum 2018 erratum corrigendum niveau 2 mathématiques ; curriculum primary Class 3–6 errata 2018.
