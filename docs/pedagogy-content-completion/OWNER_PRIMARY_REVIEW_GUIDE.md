# Revue primaire — trois décisions distinctes

Ouvrir la Preview Staging livrée, puis Pédagogie → Programme → Validation du
référentiel, avec le compte owner. La protection Vercel reste active.

## Étape 1 — Valider les niveaux

Douze rattachements MINEDUB sont présentés avec source et justification.
Sélectionner les niveaux souhaités, saisir une note, puis « APPROUVER LES NIVEAUX
SÉLECTIONNÉS ». Vérifier le récapitulatif et confirmer. Rien n'est présélectionné.
Les versions techniques sont accessibles dans « Voir les détails ».

## Étape 2 — Correspondances de matières sûres

Le catalogue observé produit 42 EXACT et 34 SAFE_ALIAS. La liste est calculée
depuis les matières actuelles de l'établissement ; elle peut évoluer si ce
catalogue change. Sélection par matière ou par classe, aucune sélection initiale.
Le récapitulatif indique le nombre de classes et de correspondances.
Annuler ne modifie rien ; confirmer enregistre uniquement les matières choisies.

Une ancienne proposition n'est pas une décision. « MAPPING VALIDÉ » exige un
niveau approuvé sur sa version courante et une correspondance explicitement
approuvée sur sa propre version courante. Ce n'est jamais « MATIÈRE ENSEIGNÉE ».

## Étape 3 — Décisions nécessaires

Seules les 44 ambiguïtés du catalogue observé apparaissent ici.

- RELIER À CE DOMAINE : choisir explicitement une matière candidate et expliquer
  pourquoi son périmètre convient. Le lien est documentaire, pas une adoption.
- CONSERVER COMME MATIÈRE ITALO DISTINCTE : choisir la matière concernée ; cette
  décision ne la relie pas au domaine officiel et ne modifie pas le catalogue.
- NON APPLICABLE : expliquer la décision pour ce domaine dans cette classe.
- À REVOIR PLUS TARD : enregistrer le point à éclaircir ; le cas reste non résolu.

Chaque décision individuelle demande une justification et une confirmation.
Les versions, la révision, l'auteur, la date serveur, l'historique et l'audit sont
conservés. Une révision concurrente ou une source modifiée impose un rechargement.
Après une réponse incertaine, recharger et vérifier avant de recommencer.

Français seul ne devient pas automatiquement Français et littérature. Ces cas
restent ambigus ; aucun reclassement n'a été effectué pour modifier les compteurs.

## Hors de cette revue groupée

Les huit niveaux préscolaires conservent leurs réserves et feront l'objet d'une
revue séparée. Les 95 correspondances secondaires partielles restent préparées,
sans application automatique, dans les dossiers documentaires complets.
Les séries, combinaisons et disciplines réellement ouvertes seront traitées
séparément. La secrétaire peut consulter, mais aucun contrôle de décision owner
ne lui est ouvert.

Aucune affectation enseignant, adoption, configuration enseignée, horaire,
coefficient ou validation pédagogique n'est créé par ces actions.
Production reste interdite. Aucun appel OpenAI dans cette livraison.
