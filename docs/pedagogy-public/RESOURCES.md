# Original resource library

The resources route provides eight original assistant-authored project templates:
French and English variants for pre-nursery, nursery, primary and secondary.
Each contains an objective, materials, activity steps, differentiation,
observation guidance and safety notes. Text downloads include the stable ID,
version, authorship and pending-review warning. The route loads on demand;
filtering and downloads do not call an AI provider or read pupil records.

These are **draft activity proposals**, not official curriculum coverage,
teacher approvals, records of teaching, authenticated exam papers or CEDUC
content. There is no automatic class adoption or assessment generation.
No third-party document is reproduced. No protected answer key or internal
school document is embedded in the public application bundle.

Secretary workflow:

1. Open Pedagogy > Resources and select language/cycle.
2. Read the proposed activity and download its text if useful.
3. Obtain the teacher's adaptation and decision outside this draft library.
4. Use the existing preparation workflow for the returned actual document.
5. Record teaching only after receiving the corresponding declaration.

Eleven local resource tests passed: bilingual coverage/provenance, filtering,
download selection and URL cleanup. The existing synthetic secretary browser
scenario also checks a real English text download and deletes that file.
Its result must be linked to the resulting CI SHA before claiming it passed.

Institutional documents, authenticated exam papers, CEDUC rights/connectivity
and controlled source monitoring remain separate unfinished deliverables.
